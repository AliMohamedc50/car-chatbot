# 🚗 مساعد العربيات (شات بوت بالعامية المصرية)

شات بوت بيساعد المستخدم:
1. **يلاقي عربية** حسب الميزانية والمواصفات.
2. **يفهم عطل** في العربية من الأعراض (كتابة، صوت، أو صورة).

> الشات بوت بيجاوب **من ملف الإكسيل بس** (`cars_chatbot_data.xlsx`) ومبيألفش أسعار ولا حلول من عنده.
> بيشتغل على **Google Gemini API (الـ free tier المجاني)**، يعني من غير أي تكلفة.

## الفكرة باختصار (للشرح للدكتور)
- **Streamlit**: واجهة الويب.
- **Gemini + Function Calling**: الموديل بيفهم كلام المستخدم وبيطلب أداتين: `search_cars` و `search_faults`. إحنا بننفّذ البحث على الإكسيل ونرجّعله النتيجة، وهو بيصيغ الرد منها بس.
- **ملف واحد بس بيكلّم المزوّد**: `chatbot/llm.py` (واجهة صغيرة + تنفيذ Gemini). لو عايزين نبدّل المزوّد بعدين نكتب كلاس جديد من غير ما نلمس باقي الكود.
- **بحث العربيات**: فلترة بـ pandas (سعر، ماركة، مواصفات). لو مفيش نتايج بنوسّع السعر 15% وبعدها بنشيل المميزات الاختيارية.
- **بحث الأعطال**: TF-IDF (حروف + كلمات) مع تطبيع عربي، ودفعة للكلمات المفتاحية المصرية. لو التشابه ضعيف بيرجّع "مفيش تطابق مؤكد".
- **الصور**: بتتصغّر وتتبعت للموديل كجزء صورة، بيوصف اللي شايفه وبعدين لازم يبحث في الأعطال.
- **الصوت**: ميكروفون (ar-EG) + قراءة الرد من المتصفح.

## هيكل المشروع
```
app.py                  واجهة Streamlit
chatbot/
  normalize.py          تطبيع النص العربي
  data_loader.py        قراءة الإكسيل وتنضيفه
  retriever.py          البحث (عربيات + أعطال)
  tools.py              تعريف الأدوات وتنفيذها (+ كاش للنتايج)
  llm.py                الكلام مع Gemini (الملف الوحيد المرتبط بالمزوّد)
  agent.py              لوب الأدوات + معالجة الصور
  prompts.py            تعليمات النظام
tests/                  اختبارات pytest (بإكسيل وهمي وLLM وهمي)
```

## إزاي تجيب مفتاح Gemini مجاني
1. افتح **https://aistudio.google.com/app/apikey** وسجّل دخول بحساب جوجل.
2. اضغط **Create API key** (اختار مشروع جديد أو موجود).
3. انسخ المفتاح. **متنشروش ومتحطوش في الكود ولا على GitHub.**

لا محتاج كارت بنكي في الـ free tier. الحد المجاني له سقف على عدد الطلبات في الدقيقة واليوم (بيتغيّر حسب الموديل، تقدر تشوفه من صفحة الـ Rate limits في AI Studio).

## تشغيل على جهازك
```bash
python -m venv .venv
source .venv/bin/activate        # على ويندوز: .venv\Scripts\activate
pip install -r requirements.txt
cp .streamlit/secrets.toml.example .streamlit/secrets.toml   # وحط مفتاحك جواه
# حط ملف cars_chatbot_data.xlsx جنب app.py
streamlit run app.py
```
ملف `.streamlit/secrets.toml` بيبقى كده:
```toml
GEMINI_API_KEY = "المفتاح-بتاعك"
```
أو بدل الملف استخدم متغير بيئة: `export GEMINI_API_KEY=...` (على ويندوز PowerShell: `$env:GEMINI_API_KEY="..."`).

## تشغيل الاختبارات
```bash
pip install -r requirements-dev.txt
python -m pytest -q
```
الاختبارات **مش محتاجة مفتاح ولا إنترنت**: بتستخدم إكسيل وهمي وعميل Gemini وهمي، وبتتأكد من التطبيع، قواعد التنضيف، فلترة العربيات، البحث في الأعطال، لوب الأدوات، إعادة المحاولة عند 429، والكاش.

## النشر على Streamlit Community Cloud
1. ارفع المشروع على GitHub (**من غير** `secrets.toml`، الـ `.gitignore` بيمنعه). ملف الإكسيل لازم يكون مرفوع معاه.
2. ادخل على share.streamlit.io واختار الريبو والملف `app.py`.
3. من **Settings ← Secrets** (أو من Advanced settings وإنت بتعمل Deploy) الصق:
```toml
GEMINI_API_KEY = "المفتاح-بتاعك"
APP_PASSWORD = "باسورد-اختياري"
```
4. اضغط Deploy. لو غيّرت الـ Secrets بعدين، اعمل Reboot للتطبيق.

### الإعدادات (Secrets أو متغيرات بيئة)
| الاسم | الافتراضي | الشرح |
|---|---|---|
| `GEMINI_API_KEY` | – | **مطلوب** |
| `GEMINI_MODEL` | `gemini-3.5-flash-lite` | اسم الموديل (Flash-Lite، مجاني، بيدعم الأدوات والصور) |
| `GEMINI_THINKING_LEVEL` | – | اختياري: `MINIMAL` / `LOW` / `MEDIUM` / `HIGH` |
| `APP_PASSWORD` | – | لو موجود تظهر شاشة باسورد |
| `MAX_MESSAGES` | 20 | أقصى رسايل في الجلسة |
| `MAX_IMAGE_MB` | 5 | أقصى حجم للصورة |
| `MAX_TOKENS` | 2048 | أقصى طول للرد (بيشمل tokens التفكير) |

لو اسم الموديل اتغيّر أو اتقفل، شوف الأسماء الحالية في https://ai.google.dev/gemini-api/docs/models وحطه في `GEMINI_MODEL`.

## إزاي الزملاء يحدّثوا الإكسيل
1. عدّل `cars_chatbot_data.xlsx` **من غير ما تغيّر أسماء الأعمدة أو الشيتات**.
2. لازم عمود `Data_Check` يبقى `OK` في الصفوف اللي عايزينها تظهر.
3. اعمل commit و push على GitHub، والتطبيق هيتحدّث تلقائيًا (أو اعمل Reboot من لوحة Streamlit).
4. لو في خطأ (شيت أو عمود ناقص) التطبيق بيقولك بالظبط إيه الناقص. وفي الشريط الجانبي قسم "ملاحظات على البيانات" بيعرض الصفوف اللي اتجاهلت.

## حماية الحد المجاني
- **20 رسالة كحد أقصى** في الجلسة (`MAX_MESSAGES`).
- بنبعت **آخر 6 تبادلات** بس كسياق، وفيه حد لطول الرد وحجم الصورة.
- **كاش** لنتايج البحث المتكررة في الإكسيل.
- لو جوجل رجّعت **429** (تجاوز الحد) التطبيق بيعيد المحاولة مرة واحدة بعد انتظار بسيط، ولو فشلت يظهر: «الخدمة مشغولة، جرب بعد دقيقة».
- لو الحد اليومي خلص، هيشتغل تاني تلقائيًا لما يتجدد.

## ملاحظات
- الميكروفون والرد الصوتي بيشتغلوا الأحسن على **Google Chrome**، ولو المتصفح مش داعم بتظهر رسالة.
- حد الرسايل بيتصفّر لو المستخدم عمل ريفرش للصفحة، فالحد الحقيقي هو حدود الـ free tier نفسها عند جوجل.
- في الـ free tier جوجل ممكن تستخدم المحتوى المبعوت لتحسين منتجاتها (راجعوا شروط Gemini API). فمتبعتوش صور أو بيانات شخصية حساسة.
